2Instalar (una sola vez)

Abre PowerShell en la carpeta donde quieras el proyecto:

git clone https://github.com/AnggieSweet/taller-grupo4-AnggieGustavoEnriqueChristian.git cd taller-grupo4-AnggieGustavoEnriqueChristian

Permite ejecutar scripts y activa las tildes en esta ventana (repítelo cada vez que abras una terminal nueva):

Set-ExecutionPolicy -Scope Process Bypass [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
.\instalar.ps1

Crea los dos entornos virtuales, instala las dependencias y crea .env y bruno/.env a partir de los ejemplos. Tarda unos minutos.

py -3.13 -m venv .venv .\.venv\Scripts\python.exe -m pip install -r requirements.txt py -3.13 -m venv .venv-crew .\.venv-crew\Scripts\python.exe -m pip install -r requirements-crew.txt Copy-Item .env.example .env Copy-Item bruno/.env.example bruno/.env

.venv se usa para la API y casi todos los agentes. .venv-crew es solo para el agente de restaurantes (CrewAI).

Abre el archivo .env y completa estas variables. Las demás (URLs y puertos) ya vienen listas.

Para generar API_KEY y TELEGRAM_SECRET, ejecuta este comando una vez por cada una:

.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(32))"

Luego abre bruno/.env y pon la misma API_KEY:

bruno/.envAPI_KEY=tu-clave
Sin comillas. Si escribes API_KEY="abc", Bruno envía las comillas y la API responde 401.
Los archivos .env y bruno/.env nunca se suben a GitHub. No los compartas ni los muestres en capturas.

8Telegram

Cada persona debe crear su propio bot: el token del grupo no está en el repositorio.

Crear el bot

  1. Abre Telegram (app o web.telegram.org) y busca @BotFather (con ✔️ azul).
  2. Envía /newbot, escribe un nombre (ej. Mall Pruebas) y un username que termine en bot (ej. mall_pruebas_bot).
  3. Copia el token que te entrega en .env → TELEGRAM_TOKEN.
  4. Genera TELEGRAM_SECRET (comando del paso 3) y deja TELEGRAM_PERMITIDOS= vacío.
El token es secreto: quien lo tenga controla tu bot. No lo muestres en capturas.

Conectar el bot

Con los agentes y la API ya levantados (paso 4), en otra terminal:

.\.venv\Scripts\python.exe -m scripts.telegram_local

Espera el mensaje "Escribe a tu bot en Telegram. Ctrl+C para detener". Puede tardar hasta 2 minutos. Deja esa terminal abierta.

Autorizar tu chat

  1. Escribe a tu bot. Responderá "No autorizado. Tu chat_id es X".
  2. Pon ese número en .env → TELEGRAM_PERMITIDOS=X (varios, separados por comas).
  3. Reinicia la API: .\detener.ps1 y luego .\iniciar.ps1. El script del túnel puede seguir abierto.
  4. Vuelve a escribir al bot.

?Problemas comunes

"La ejecución de scripts está deshabilitada en este sistema"

Ejecuta esto en la misma terminal y vuelve a intentar:

Set-ExecutionPolicy -Scope Process Bypass
"Ya existe logs/pids.txt"

Quedó un arranque anterior. Ejecuta .\detener.ps1 y luego .\iniciar.ps1.

"Puerto X ocupado"

Hay un agente o API corriendo de antes. Ciérralo con Ctrl+C en su terminal, o libera todos los puertos con:

Get-NetTCPConnection -LocalPort 8000,8001,8003,8004,8005,8006,8010 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

Luego ejecuta .\detener.ps1 y .\iniciar.ps1.

Aparece >> y no pasa nada

PowerShell cree que el comando está incompleto (pasa al pegar con caracteres invisibles). Presiona Ctrl+C y escribe el comando a mano.

/chat responde 502

La API se inició antes que los agentes. Ejecuta .\detener.ps1 y .\iniciar.ps1 (el script respeta el orden). Si persiste, revisa logs\<agente>.log.

Responde 504 o "Hubo un problema, intenta de nuevo"

Gemini está lento o saturado (error 503 de alta demanda). Espera unos segundos y reintenta.

Todo da 401 en Bruno

Revisa: entorno local seleccionado, bruno/.env con la misma API_KEY que .env, sin comillas, y reinicia Bruno.

El script de Telegram dice que /health no respondió

Comprueba que la API esté arriba (curl.exe http://localhost:8010/health). Si responde, el túnel tardó en activarse:

ipconfig /flushdns .\.venv\Scripts\python.exe -m scripts.telegram_local

Límites conocidos

  • El modelo ignora la temperatura: las respuestas pueden variar entre ejecuciones.
  • Restaurantes solo cubre Lima, Bogotá y Buenos Aires.
  • La cartelera de cine es de ejemplo y la misma todos los días.
  • La memoria vive en RAM y se pierde al reiniciar la API.
  • Telegram usa un túnel temporal y solo procesa mensajes de texto.
